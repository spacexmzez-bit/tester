Google Play 12-Tester & Cloudflare Setup Guide

Overview: Zero-Overengineering Cross-Device Sync

This site is completely static (hosted on GitHub Pages) and uses a simple, secure Cloudflare Worker to sync state across devices using a private Sync Passkey stored in Cloudflare KV.

Step 1: Push repository to GitHub

Push index.html, setup.html, worker.js, and wrangler.toml to your GitHub repository.

Step 2: Enable GitHub Pages

In your GitHub repository, open Settings → Pages. Under Source, select GitHub Actions. The included deploy.yml workflow will automatically publish your site on every push.

Step 3: Deploy Cloudflare Worker & KV

# 1. Login to Cloudflare
npx wrangler login
# 2. Create the KV namespace
npx wrangler kv:namespace create PLAY_TESTER_KV
# 3. Paste the returned ID into wrangler.toml
# 4. Deploy worker
npx wrangler deploy

Step 4: Connect Your Devices

Open Settings (⚙) in the top navigation, paste your Worker URL (e.g. https://play-tester-sync.yourname.workers.dev) and set your private Sync Passkey. Enter the exact same passkey on your other phone or computer, and your data syncs automatically!
